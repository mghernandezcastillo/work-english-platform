## 🔧 Mejoras Pendientes (por prioridad)

### 🔴 Alta Prioridad

- [ ] **Subir presupuesto** — De $10,000 a $20,000-$30,000 COP/día
- [ ] **Cambiar CTA del anuncio** — De "Más información" → "Obtener oferta"
- [ ] **Crear nueva campaña con objetivo "Ventas"** — En paralelo a la campaña actual de Tráfico

### 🟡 Media Prioridad

- [ ] **Crear versión del anuncio SIN precio en la imagen** — El precio en la imagen mata la curiosidad y reduce el poder de la landing
- [ ] **Activar segundo anuncio** — Ad 01 o Ad 03 (ángulo Dolor) en el mismo Ad Set para que Facebook compare
- [ ] **Probar Campaña 3 — Call Center (Carousel)** — Segundo ángulo para diversificar

### 🟢 Después de $150,000 COP invertidos

- [ ] **Evaluar CTR** — Si CTR > 1% pero 0 ventas → problema es la landing. Si CTR < 0.5% → problema es el anuncio
- [ ] **Activar Campaña de Retargeting** — Para personas que visitaron la landing pero no compraron
- [ ] **Probar diferentes audiencias** — Expandir/reducir intereses según rendimiento

## 📋 Reglas de Decisión

| Escenario | Acción |
|-----------|--------|
| CTR > 1% + 0 ventas después de 100 clics | Revisar landing page |
| CTR < 0.5% después de 5 días | Cambiar imagen/texto del anuncio |
| CPC > $1,500 COP | Ampliar audiencia (más intereses) |
| 0 ventas después de $150,000 COP gastados | Pausar, revisar embudo completo |
| Primera venta confirmada | 🎉 Escalar presupuesto x2 |
