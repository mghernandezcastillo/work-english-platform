```

├── AD SET 1: Interest — English learners (Colombia)

│
├── AD SET 2: Interest — Job seekers (Colombia)

│
├── AD SET 3: Interest — Call center workers (Colombia)
│   ├── Ad 3A-3D
│
├── AD SET 4: Lookalike — Purchasers (after 50+ sales)
│   ├── Ad 4A-4D
│
├── AD SET 5: Retargeting — Landing page visitors (7 days)
│   ├── Ad 5A-5D (reminder angle)
│
└── AD SET 6: Retargeting — Cart abandoners (3 days)
    ├── Ad 6A-6D (urgency angle)
```

## Targeting

### Interest targeting (launch)

| Ad set | Interests to target |
|---|---|
| English learners | English language, Learn English, IELTS, TOEFL, British Council, American English |
| Job seekers | Job search, LinkedIn, CV, Resume, Career development |
| Call center workers | Call center, Customer service, BPO, Teleperformance, Alorica, Concentrix |

### Demographics

| Parameter | Value |
|---|---|
| Age | 22-38 |
| Gender | All |
| Location | Colombia (primary), then México |
| Language | Spanish |
| Placements | Feed, Stories, Reels (mobile only) |

### Lookalike audiences (after 50+ sales)

1. Lookalike from purchasers (1%)
2. Lookalike from landing page visitors (2%)
3. Lookalike from engagement (3%)

### Retargeting (after pixel fires)

1. Landing page visitors (7 days) — not yet purchased
2. CTA clickers (3 days) — didn't complete purchase
3. Purchasers — exclude from acquisition campaigns

## Budget phases

| Phase | Daily budget | Duration | Objective |
|---|---|---|---|
| **Testing** (Week 1-2) | $10-20 USD/day | 14 days | Find winning ad + landing combo |
| **Scaling** (Week 3-4) | $30-50 USD/day | 14 days | Scale winning combos |
| **Optimization** (Month 2+) | $50-100 USD/day | Ongoing | Maximize ROAS |

### Testing rules

1. Run each ad for minimum 3 days before judging
2. Need at least 1,000 impressions per ad for valid data
3. Kill ads with CPA > 25,000 COP after 3 days
4. Scale ads with CPA < 15,000 COP
5. Test one variable at a time (headline OR image OR audience — not all)

## Facebook Pixel events

| Event | When it fires | Purpose |
|---|---|---|
| `PageView` | Any page load | Basic tracking |
| `ViewContent` | Landing page load | Landing page reach |
| `InitiateCheckout` | CTA click (Hotmart redirect) | Funnel tracking |
| `Purchase` | Hotmart webhook confirms sale | Conversion tracking |
| `CompleteRegistration` | User registers in app | Post-purchase tracking |
