# Content Architecture — English for Work

> Source: `00-master-prd.md` Section 8

---

## Structure overview

```
3 Routes → 9 Modules → 36 Lessons → 12 Simulations
220-280 Phrases → ~300 Audio clips → ~103 min total audio
```

## Content structure per lesson (JSON format)

Each lesson is stored as a JSON object with this structure:

```json
{
  "id": "1.1.1",
  "moduleId": "1.1",
  "title": "Cómo describir tu experiencia",
  "objective": "Después de esta lección vas a poder describir tu experiencia laboral en inglés de forma clara",
  "steps": {
    "phrases": [
      {
        "english": "I have 3 years of experience in customer service.",
        "spanish": "Tengo 3 años de experiencia en servicio al cliente.",
        "pronunciation": "ai hav zri yirs of ex-PIR-iens in COS-to-mer SER-vis",
        "context": "Usa esta frase al inicio de una entrevista o cuando te pregunten sobre tu experiencia.",
        "audioFile": "r1-m1-l1-phrase-01.mp3"
      }
      // ... 5-7 more phrases
    ],
    "miniExample": {
      "type": "dialogue",
      "exchanges": [
        { "speaker": "Interviewer", "text": "Can you tell me about your experience?", "audioFile": "r1-m1-l1-example-01a.mp3" },
        { "speaker": "You", "text": "Sure. I have 3 years of experience in customer service at a call center.", "audioFile": "r1-m1-l1-example-01b.mp3" }
      ]
    },
    "explanation": "Nota cómo usamos 'I have X years of experience in...' — esta es la estructura más natural en inglés para hablar de experiencia. No digas 'I have experience of 3 years', suena raro.",
    "exercises": [
      {
        "type": "fill-blank",
        "instruction": "Completa la frase:",
        "sentence": "I have ___ years of ___ in customer service.",
        "blanks": ["3", "experience"],
        "feedback": {
          "correct": "¡Perfecto! 'I have X years of experience in...' es la estructura correcta.",
          "incorrect": "Recuerda: 'I have [número] years of experience in [área].'"
        }
      }
    ],
    "guidedPractice": {
      "scenario": "Estás en una entrevista de trabajo. El reclutador te pregunta sobre tu experiencia.",
      "steps": [
        {
          "prompt": "El reclutador dice: 'Tell me about your work experience.'",
          "options": [
            { "text": "I have 3 years of experience in customer service.", "correct": true, "feedback": "¡Excelente! Directo y profesional." },
            { "text": "I work in customer service for 3 years.", "correct": false, "feedback": "Casi. Lo correcto es 'I have worked' o 'I have 3 years of experience in...'" }
          ]
        }
      ]
    },
    "reinforcement": {
      "summary": "En esta lección aprendiste a describir tu experiencia usando 'I have X years of experience in...' y otras frases clave.",
      "keyPhrases": ["I have X years of experience in...", "I worked as a...", "My main responsibilities were..."],
      "nextPreview": "En la siguiente lección vas a aprender a escribir tu resumen profesional."
    }
  }
}
```

## Content volume targets

| Element | Per lesson | Total (36 lessons) |
|---|---|---|
| Key phrases | 6-8 | 220-280 |
| Mini examples | 1 | 36 |
| Exercises | 1-2 | 36-72 |
| Guided practice scenarios | 1 | 36 |
| Audio clips (phrases) | 6-8 | 220-280 |
| Audio clips (examples) | 1-2 | 36-72 |
| Simulation audio clips | — | ~60 (12 sims × ~5 clips) |
| **Total audio clips** | — | **~300** |
