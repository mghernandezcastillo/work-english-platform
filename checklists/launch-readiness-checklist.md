# Launch Readiness Checklist — English for Work

> THE FINAL GO/NO-GO CHECKLIST — Day of launch

---

## 🟢 Go if ALL items are checked

- [ ] `checklists/launch-checklist.md` is 100% complete
- [ ] Real purchase test completed successfully in the last 24 hours
- [ ] At least 3 real testimonials visible on landing pages
- [ ] No critical bugs open
- [ ] Facebook Ads campaign ready (paused, waiting activation)
- [ ] Operator has access to all dashboards:
  - [ ] Supabase dashboard
  - [ ] Facebook Ads Manager
  - [ ] Hotmart dashboard
  - [ ] Resend dashboard
  - [ ] Cloudflare dashboard
- [ ] WhatsApp support number active
- [ ] Operator available to monitor for first 4 hours after launch

## 🔴 No-go if ANY of these are true

- [ ] Hotmart webhook not working
- [ ] Emails going to spam
- [ ] App crashes on mobile
- [ ] Audio not playing
- [ ] Landing page takes > 3 seconds to load
- [ ] Testimonials not displaying
- [ ] Facebook Pixel not verified
